# V17.5 Image assets

Place optimized images in the folders below. Prefer `.webp` for photos; `.svg` for UI icons; `.png` for PWA icons.

## Folders

| Folder | Planned files |
|--------|----------------|
| `brand/` | `brand-mark.webp`, `brand-mark-192.png`, `brand-mark-512.png` |
| `portals/` | `portal-books.webp`, `portal-hr.webp`, `portal-visitor.webp` |
| `books/` | `book-satyanisodh-cover.webp`, `book-astitva-garima-cover.webp`, `book-mahabharat-rajdharma-cover.webp`, `book-pushtimarg-cover.webp`, `books-catalogue-hero.webp` |
| `hr/` | `hr-portrait.webp`, `hr-portrait-square.webp`, `hr-projects-hero.webp` |
| `visitor/` | `visitor-about-hero.webp`, `visitor-mewad-hero.webp`, `visitor-vanshavali-hero.webp` |
| `ui/` | `ui-offline.svg`, `ui-404.svg`, `ui-search-empty.svg` |
| `social/` | `og-default.webp` |

## Naming rules

- lowercase-kebab-case only
- no spaces, no Gujarati in filenames
- size suffixes: `-192`, `-512`, `-square`, `-hero`, `-cover`
